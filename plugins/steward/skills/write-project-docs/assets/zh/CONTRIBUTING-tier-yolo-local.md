## 当前开发策略

**开发档位：`YOLO_LOCAL`**

在用户明确声明的可丢弃本地工作区内，以最短路径完成 [`{{PRODUCT_DOC}}`]({{PRODUCT_DOC}}) 的可观察目标。该档位允许激进的局部实现选择，但不扩大宿主、账户或外部系统权限。本档位永久豁免安全、隐私、数据、密钥与凭据管理、兼容、审计/监控/SLO 和法规合规要求的主动投入。

### 本档位必须完成

- 完成当前目标的最小可运行闭环，并产生至少一项真实、可重复观察的结果。
- 把全部修改和破坏性影响限制在已确认的可丢弃本地工作区与临时数据内。
- 对直接受影响路径运行足以证明目标成立的最小冒烟验证。

### 默认不投入

- 永久豁免安全、隐私、数据治理、密钥与凭据管理、权限体系、兼容层与兼容回归、审计/监控/SLO、法规合规等合规要求的主动投入；不主动投入全量测试、仓库级门禁、长期文档、性能优化、高可用或生产加固。
- 不为未验证需求增加抽象、扩展点、迁移机制或通用基础设施。

### 不可越过的边界

- 不处理真实、个人、生产或不可丢弃数据，不使用生产凭据，不接入外部用户或外部流量。
- 不执行任何外部写入、部署、发布、购买或第三方账户变更。
- 不破坏工作区外文件、宿主环境或未明确声明为可丢弃的状态，不虚构验证结果。
- 用户明确要求、已接受 GOAL、项目硬规则/不变量和 [`STATUS.md`](STATUS.md) 明确禁止事项仍然有效，不受豁免影响；真实数据、生产凭据、外部用户、外部流量或不可丢弃状态出现时按切换条件退出档位。

### 切换条件

- 一旦需要真实数据、生产凭据、外部用户、外部流量、外部副作用或不可丢弃状态，立即退出 `YOLO_LOCAL` 并选择至少 `EXPERIMENT` 或更严格档位。
- 当目标转为验证产品价值时切换到 `MVP`；准备有限真实用户时切换到 `PILOT`。
