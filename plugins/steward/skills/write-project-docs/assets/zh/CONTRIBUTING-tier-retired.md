## 当前开发策略

**开发档位：`RETIRED`**

停止普通功能开发，以安全、可验证地终止服务、访问、凭据和数据责任为唯一交付方向。

### 本档位必须完成

- 关闭或隔离全部入口、后台任务、集成和仍可达的运行表面。
- 撤销凭据和权限，并按权威政策完成数据导出、保留、迁移或删除。
- 验证下线结果、残余依赖、用户通知和必要审计证据。

### 默认不投入

- 不开发新功能，不进行与下线无关的性能优化、架构重写或平台扩建。
- 不保留没有明确剩余责任的兼容层、凭据、数据副本或运行资源。

### 不可越过的边界

- 任何仍然可达的接口、数据、凭据和用户路径继续满足适用的安全、隐私和兼容要求。
- 不在缺少授权、保留政策或恢复证据时删除不可丢弃数据。

### 切换条件

- 只有在重新确认产品目标、用户责任和运行边界后，才能切回 `EXPERIMENT`、`MVP`、`PILOT` 或 `PRODUCTION`。
- 全部入口、凭据、数据责任和支持承诺关闭后，保持 `RETIRED` 并停止工程变更。
