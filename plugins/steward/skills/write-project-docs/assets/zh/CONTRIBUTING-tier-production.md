## 当前开发策略

**开发档位：`PRODUCTION`**

以持续、安全、兼容、可观察和可恢复的生产运行作为默认完成标准。

### 本档位必须完成

- 满足适用的安全、隐私、访问控制、数据完整性、兼容迁移和密钥管理要求。
- 建立并验证备份恢复、迁移回滚、监控告警、事件响应以及已承诺性能或 SLO。
- 运行覆盖受影响功能、失败恢复、兼容性和生产风险的全部必需检查与回归。

### 默认不投入

- 不主动实现与当前产品目标、生产风险、兼容承诺或运维责任无关的附加功能和清理工作。
- 不为假设中的未来规模引入未经证据支持的复杂架构。

### 不可越过的边界

- 不削弱现有安全、数据、兼容、可用性和审计承诺，不用局部交付压力替代生产完成标准。
- 高后果变更必须具备可验证的回滚、恢复或等效补偿控制。

### 切换条件

- 当产品停止主动演进但仍承担支持和兼容责任时切换到 `MAINTENANCE`。
- 当确认停止服务并进入下线流程时切换到 `RETIRED`。
