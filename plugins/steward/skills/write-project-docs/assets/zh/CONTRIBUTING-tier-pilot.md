## 当前开发策略

**开发档位：`PILOT`**

以受控范围支撑有限真实用户和真实反馈，在保持可回滚的前提下验证产品、数据和运行流程。

### 本档位必须完成

- 为实际用户路径实施认证、授权、隐私、数据完整性和必要兼容保护。
- 建立可验证的数据迁移、备份或回滚路径，以及支持试点问题定位的日志、指标和告警。
- 覆盖核心流程、受影响兼容面、主要失败模式和恢复路径，并记录试点反馈条件。

### 默认不投入

- 不主动建设超出试点用户量和流量的容量、全局高可用、多区域容灾或长期规模优化。
- 不扩展与试点目标、风险或反馈无关的功能和平台能力。

### 不可越过的边界

- 不以试点范围有限为由削弱真实用户、真实数据、凭据和可达接口的保护。
- 不执行没有回滚或恢复证据的高后果迁移，不违反现有兼容与数据承诺。

### 切换条件

- 当试点结束且停止真实使用时，根据后续目标切换到 `MVP`、`MAINTENANCE` 或 `RETIRED`。
- 当准备一般可用性、持续运营或明确 SLO 时切换到 `PRODUCTION`。
