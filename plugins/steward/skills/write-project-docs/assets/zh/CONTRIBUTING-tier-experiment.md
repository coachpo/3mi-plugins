## 当前开发策略

**开发档位：`EXPERIMENT`**

以最小、可逆且可观察的实现验证技术假设，优先减少关键不确定性，而不是完成完整产品或长期架构。

### 本档位必须完成

- 明确本次实验的假设、可观察成功或失败条件以及退出条件。
- 实现能隔离关键变量的最小验证路径，并保留真实实验结果。
- 对触及的凭据、数据、权限和外部接口应用与实际可达风险相称的保护。

### 默认不投入

- 不主动追求产品完整性、广泛兼容、全面回归、规模化、高可用、生产级可观测性或与实验无关的安全专项。
- 不把实验性实现扩展为通用框架，也不把候选设计表述为当前正式架构。

### 不可越过的边界

- 实验档位不授权外部写入、破坏现有数据、泄露凭据或绕过明确项目规则。
- 已有外部用户、真实数据、兼容承诺和可达安全风险仍约束实现与验证。

### 切换条件

- 当技术假设已经得到足够证据并开始验证端到端产品价值时切换到 `MVP`。
- 当实验接入有限真实用户或不可丢弃数据时至少切换到 `PILOT`。
