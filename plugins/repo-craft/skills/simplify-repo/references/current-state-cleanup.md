# 现状文档清理

这些判据是对[精简仓库](../SKILL.md)中保全义务的补充。

- 对照当前源码、配置和迁移核对文档中的说法；不从旧日志推断线上状态。未能核实的说法是不确定，不是错误。
- 执行日志与验收日志、操作记录、已完成的迁移或修复叙述、“先前是 X，后来改为 Y”式的说明，以及被取代的笔记或提案，在不承担后续义务时删除。
- 保留初始化、部署、迁移、恢复等可重复操作的操作手册，以及当前代码仍然支持的历史数据或协议处理。
- 区分执行日期和源码核实日期。仅有带日期的标题不构成删除理由；保留核实日期以及必需的验收或审计证据。
- 把关于已退役资源的警告改写成不带时间线的现行约束，保留防止复用或误操作所需的标识符。
- 宁可删除过时的部分，也不改写仍然有效的内容。部分过时的句子只删掉过时的分句；不编造替代的事实。
