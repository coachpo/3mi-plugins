# 模板写入与合并

只在目标文件属于本次初始化或维护范围时写入。**只读审查**只报告缺失、重复和冲突，不创建或修改文件。

- **目标不存在或为零字节**：将完整模板写入目标文件。不要按项目类型、工具、部署状态或当前是否用得到来筛选、改写或省略规则。规则正文中的“如果……则……”原样保留，它约束今后的操作，不是写入条件。唯一的例外：用户在本次请求或此前的对话中说明的项目规则，取代与之矛盾的模板条款；只替换矛盾的部分，并在报告中列出被取代的条款。
- **目标为非空文件**：逐条按含义比较，而不是按标题、段落或措辞比较。文件里已经写下的规则不属于上一条的例外，即使它出自用户之手，也按本条和下一条处理。保留原有结构和项目特有内容；等义规则沿用原文、不重复追加；缺失且不冲突的规则直接合入对应位置。一段有多项要求时分开处理，只暂缓互不相容的那一项。
- **发生冲突**：先合并其余规则，再集中列出各冲突项的现有条款和模板条款，逐项询问：“用模板覆盖这条现有政策，还是跳过这条模板政策？”答复前保留原条款，不并列写入相反要求。选择覆盖只替换冲突部分；选择跳过就保留原文、不写入该项。未获答复的项不自行决定。
- **规则属于另一份模板**：非空目标里的规则，或一条规则里的某项要求，若与另一份模板的条款等义，它归那份模板对应的文件，不留在这里，即使它所在的规则比本模板的条款多出这一项。那个文件属于本次范围时，先确认该条款已在其中，再从目标文件删除它，规则的其余部分照常与本模板比较；小节因此变空就连同标题删除。整个小节都属于另一份模板、这份模板没有同名小节时，小节里的项目专有内容一并移到对方文件的同名小节，再删除标题，不留指向对方的转述。那个文件不在本次范围时只报告，不删除。删除和移动的内容在报告中逐条列出。

项目专有内容的位置：模板已有的主题，项目专有规则写在该小节的模板条款之后，不另起一个同主题的小节；内容较多时可在该小节内用下级标题组织。模板没有的主题才新增小节；拿不准是否同一主题时另起小节。模板条款本身逐字保留，同一小节内的条款保持原有顺序，不改写。模板的一级标题只是文件名占位，可以换成项目自己的标题，标题之下可以加一段项目引言。

核对写入结果时按条款比对：每条模板条款都逐字出现在目标文件的同名小节内，且顺序不变；另一份模板的条款不出现在这个文件里，除非对方文件不在本次范围。只有没有项目专有内容的文件才与模板逐字节一致。

不要强行覆盖目录等非普通文件，也不要借合并修改其他政策来源。模板不证明项目事实；额外写入的路径、命令、部署情况等必须有证据。
