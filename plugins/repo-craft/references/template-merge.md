# 模板写入与合并

只在目标文件属于本次初始化或维护范围时写入。**只读审查**只报告缺失、重复和冲突，不创建或修改文件。

- **目标不存在或为零字节**：将完整模板写入目标文件。不要按项目类型、工具、部署状态或当前是否用得到来筛选、改写或省略规则。规则正文中的“如果……则……”原样保留，它约束今后的操作，不是写入条件。
- **目标为非空文件**：逐条按含义比较，而不是按标题、段落或措辞比较。保留原有结构和项目特有内容；等义规则沿用原文、不重复追加；缺失且不冲突的规则直接合入对应位置。一段有多项要求时分开处理，只暂缓互不相容的那一项。
- **发生冲突**：先合并其余规则，再集中列出各冲突项的现有条款和模板条款，逐项询问：“用模板覆盖这条现有政策，还是跳过这条模板政策？”答复前保留原条款，不并列写入相反要求。选择覆盖只替换冲突部分；选择跳过就保留原文、不写入该项。未获答复的项不自行决定。

不要强行覆盖目录等非普通文件，也不要借合并修改其他政策来源。模板不证明项目事实；额外写入的路径、命令、部署情况等必须有证据。
